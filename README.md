  <a href="https://iclr.cc/virtual/2026/poster/10008144"><img src="https://img.shields.io/badge/ICLR-2026_Poster-8b0000?style=flat-square&logo=googlescholar&logoColor=white"/></a>

<p align="left"><b>FutureMind: Equipping Small Language Models with Strategic Thinking-Pattern Priors via Adaptive Knowledge Distillation</b></p>

<blockquote align="left">
Small Language Models (SLMs) are attractive for cost-sensitive, resource-limited settings, yet struggle with complex, knowledge-intensive tasks. <b>FutureMind</b> is a modular reasoning framework that equips SLMs with <i>strategic thinking-pattern priors</i> via <b>adaptive knowledge distillation</b> from LLMs. It introduces a dynamic reasoning pipeline with four key modules — <b>Problem Analysis → Logical Reasoning → Retrieval</b> — enabling structured reasoning + effective retrieval for SLMs.
</blockquote>

<p align="left">
  <a href="https://arxiv.org/pdf/2602.01222"><img src="https://img.shields.io/badge/📄_PDF-2602.01222-b31b1b?style=flat-square&logo=arxiv&logoColor=white"/></a>

<h4 align="left">
  🤝 Multi-Agent Search + RL
  <a href="https://aclanthology.org/2026.acl-long.1399/"><img src="https://img.shields.io/badge/ACL-2026-blue?style=flat-square&logo=anthropic&logoColor=white"/></a>
</h4>

<p align="left"><b>End-to-End Optimization of LLM-Driven Multi-Agent Search Systems via Heterogeneous-Group-Based Reinforcement Learning</b></p>

<blockquote align="left">
LLMs are versatile but limited by static knowledge cutoffs and single-inference controllability. <b>Multi-Agent Search Systems (MASS)</b> coordinate specialized LLM agents with search tools via task decomposition + retrieval-augmented solving. This work proposes <b>Heterogeneous-Group-Based Reinforcement Learning</b> for <b>end-to-end optimization</b> of role-specialized agents — automating what prompt-engineering / SFT previously did labor-intensively.
</blockquote>
